# Terraform Infrastructure - ShopKart

## Project Overview

This repository contains the Infrastructure as Code (IaC) for the ShopKart production environment using Terraform.

The infrastructure will be deployed on Amazon Web Services (AWS) and will be used to provision networking, compute resources, storage, security, Kubernetes clusters, monitoring, and CI/CD infrastructure.

This project is being developed as a real-world Site Reliability Engineering (SRE) hands-on project.

---

# Project Objectives

- Provision AWS infrastructure using Terraform
- Follow Infrastructure as Code (IaC) best practices
- Build reusable Terraform modules
- Deploy production-ready infrastructure
- Automate infrastructure provisioning
- Integrate with Jenkins and Azure DevOps
- Deploy applications to Kubernetes
- Implement monitoring using Prometheus and Grafana
